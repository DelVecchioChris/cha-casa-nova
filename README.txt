PIX:
A página mostra a chave 537.942.438-46 e um QR que codifica essa chave.
Observação: esse QR é um QR da CHAVE Pix (texto/CPF), não um BR Code bancário
gerado pelo Mercado Pago. Se o app do banco não reconhecer o QR, use o botão
"Copiar chave Pix".

META:
O botão "Atualizar arrecadação" no rodapé pede a senha geladeira2026.
ATENÇÃO: por ser um site estático, isso não é uma autenticação de servidor e o
valor salvo fica apenas no navegador usado para a atualização. Para sincronizar
a barra em todos os celulares seria necessário um backend/banco de dados.

CONTAGEM:
A contagem regressiva é para 10/10/2026 às 14h no horário local do visitante.

LOCALIZAÇÃO:
O botão abre uma busca no Google Maps por "Estrada Rubens 30". Como a cidade não
foi informada, o Maps pode mostrar mais de uma opção; substitua o link no HTML
pelo endereço completo quando quiser.
